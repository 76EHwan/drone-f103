# STM32F103 기반 쿼드콥터 드론 제어 프로젝트

이 프로젝트는 STM32F103C8T6 (Blue Pill) 마이크로컨트롤러를 기반으로 동작하는 소형 드론(Quadcopter)의 비행 제어 시스템 구현체입니다. 블루투스 통신을 통해 원격으로 제어 명령을 수신하며, IMU 센서를 활용하여 기체의 자세를 측정하고 4개의 모터를 정밀하게 제어합니다.

## 주요 하드웨어 구성
* **MCU**: STM32F103C8T6 (ARM Cortex-M3, 최대 72MHz)
* **IMU 센서**: LSM6DS3TR (6축 가속도 및 자이로 센서)
* **통신 모듈**: HM-19 (Bluetooth LE 5.0)
* **제어 대상**: 코어리스(Coreless) 모터 8520

## 주요 기능 및 통신 인터페이스

### 1. 센서 인터페이스 (IMU)
* **LSM6DS3TR 연동 (`spi.c`, `LSM6DS3TR.c`)**: SPI 통신 인터페이스를 활용하여 가속도계 및 자이로스코프 데이터를 빠르고 안정적으로 샘플링합니다.
* 드론의 현재 Roll, Pitch, Yaw 자세를 계산하고 비행 안정화(PID 제어 등)를 위한 기초 데이터를 수집합니다.

### 2. 블루투스 무선 원격 제어
* **HM-19 BLE 통신 (`usart.c`, `hm19.c`)**: USART 시리얼 통신을 통해 스마트폰 앱이나 외부 블루투스 조종기로부터 제어 패킷을 실시간으로 수신합니다.
* 스로틀(Throttle), 롤(Roll), 피치(Pitch), 요(Yaw)에 대한 명령을 수신하여 모터 제어 알고리즘에 전달합니다.

### 3. 정밀 모터 제어 (PWM)
* **모터 구동 (`tim.c`, `motor.c`)**: 하드웨어 타이머(TIM) 채널을 기반으로 4개의 독립적인 고해상도 PWM 신호를 생성합니다.
* 수신된 조종 명령과 센서 기반의 자세 보정값을 합산하여 4개 모터의 회전 속도를 실시간으로 조절합니다.

## 핵심 소스 코드 구조
* `Core/Src/main.c`: 시스템 클럭 설정, 하드웨어 타이머 및 인터페이스 초기화, 메인 비행 제어 루프 진입점.
* `Core/Src/LSM6DS3TR.c` / `LSM6DS3TR.h`: 6축 관성 센서(IMU) 초기화, 데이터 취득 및 필터링 로직.
* `Core/Src/hm19.c` / `hm19.h`: 블루투스 모듈 설정 및 원격 조종 패킷 파싱 로직.
* `Core/Src/motor.c` / `motor.h`: 타이머 기반의 모터 PWM 출력 제어 및 모터별 추력 분배 로직.
* `Core/Src/tools.c` / `tools.h`: 시스템에 필요한 수치 매핑, 필터링 및 공통 유틸리티 함수.
